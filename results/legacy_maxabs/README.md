# The naive-quantizer baseline

This directory is the record of the first downstream evaluation, the one the paper's appendix reports as the naive-quantizer baseline: max-abs scaling, BGE without its query instruction, SciFact at k = 5 and k = 1 and a 15,130-passage NQ mini-corpus with 100 questions, read by two hosted models (`claude-haiku-4.5`, `claude-sonnet-4.5`) through the `claude -p` command line and by `Llama-3.1-8B-Instruct` through Ollama. The pipeline of the paper's body (`scale/build_jobs.py`, `scale/run_readers.py`, `analysis/downstream_analysis.py`) supersedes it.

`final_results_full.json` holds the scored numbers of that table, produced by `analyze_full.py` from the raw responses in `raw_verdicts.tgz` (prompt sets `jobs_k5`, `jobs_k1`, `jobs_nq`, `jobs_k5_v3` and the matching `out_*` directories; extract the tarball here to re-score). `sweep_full.py` and `nq_build.py` build the prompt sets from the cached BGE embeddings of the max-abs sweeps and from BEIR-NQ unzipped under `nq/`; `regen_prompts_v3.py` writes the two-step prompt of the Llama rerun; `judge_ollama.py` answers a prompt directory with a local Ollama model; `runjob.zsh` answers one prompt with a hosted model. The hosted readers need API access and are therefore not reproducible from this repository alone; `mapping_nq.json` also fixes the 100 NQ questions that `scale/select_nq.py` keeps in the 300-question set of the body.
