# Quantization Enables Private Dense Retrieval against Malicious Servers

Code, corpora and result files behind the experiments of the paper. The Python package `pdr` is the retrieval side of the protocol: it quantizes embeddings, runs the two rounds on a plaintext matrix-vector backend and measures retrieval quality against the floating-point ranking. The verifiable matrix-vector multiplication that both rounds instantiate is the Rust crate at https://anonymous.4open.science/status/vpir-pdr; it produces the timings, whose output files are in `results/vpir/`. Every table and figure of the paper is generated by a script from the files in `results/`.

## Layout

```
src/pdr/      prototype: quantize.py, protocol.py, eval.py, embed.py, cli.py
tests/        unit tests
scale/        embedding, scale sweep, prompt sets, readers; SLURM and staging scripts
analysis/     table generators
figures/      figure generators and the standalone pgfplots files they write
data/         corpora we built: scifact_chunks/, nfcorpus_chunks/, bioasq/, nq_meta/
results/      sweeps, scale/, vpir/, jobs*/, out/, reader_outputs.tar.gz, legacy_maxabs/
```

## Setup

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/python -m pytest
```

Python 3.10 or later. The Cohere encoder needs `pip install -e '.[cohere]'` and `COHERE_API_KEY`. The parameter table needs SageMath and a checkout of the [lattice estimator](https://github.com/malb/lattice-estimator) next to this file. All commands run from the repository root.

## Rerunning the experiments

**Retrieval sweeps.** `pdr.cli sweep` encodes a BEIR corpus once (cached in `.pdr-cache/`), quantizes corpus and queries at each bit-width and runs Round 1 on the integers. `--clip 99` is the paper's quantizer; without it the sweep uses max-abs scaling, the appendix baseline. `--collapse` ranks the chunks of a chunked corpus and scores each document by its best chunk (files suffixed `__doc`). SciFact and NFCorpus are downloaded on first use; the corpora in `data/` are found by name.

```bash
for M in Snowflake/snowflake-arctic-embed-l-v2.0 embed-english-v3.0 BAAI/bge-large-en-v1.5 \
         mixedbread-ai/mxbai-embed-large-v1 intfloat/e5-large-v2 thenlper/gte-large; do
  for D in scifact nfcorpus; do
    python -m pdr.cli sweep --dataset ${D}_chunks --model $M --bits 2 3 4 5 6 7 8 --clip 99 --collapse
    python -m pdr.cli sweep --dataset $D --model $M --bits 2 3 4 5 6 7 8 --clip 99
    python -m pdr.cli sweep --dataset $D --model $M --bits 2 3 4 5 6 7 8
  done
done
```

The max-abs BGE files at the top of `results/` predate BGE's query instruction and back the naive-quantizer baseline; `results/bge_prefixed/` is what the command above produces. Cohere embeddings are not redistributed, so that column is reproducible from the CSV files but not re-encodable without a key.

**Chunked corpora.** `python scale/chunk_corpus.py --data .beir-data/scifact --out data/scifact_chunks` cuts a corpus at sentence boundaries into chunks of at most 1,536 bytes, title included, and expands the relevance labels. Outputs for SciFact and NFCorpus are shipped.

**Quality at scale.** `scale/embed_beir.py` embeds BEIR-NQ (2.68M passages) and `scale/scale_sweep.py` measures nDCG@k, Recall@k, top-1 agreement and the margin statistic on nested subsets that always contain the relevant passages. Both are self-contained and run on any GPU; `scale/stage_cluster.sh` and `scale/run_scale.sbatch` are the cluster runs (`K=5 BITS="2 3 4 5 6 8"` for the Recall@5 sweep). Results are in `results/scale/`.

**Downstream evaluation.** `scale/build_bioasq.py` builds the BioASQ endpoint from `training11b.json` (registration at bioasq.org) and `scale/select_nq.py` the 300 NQ questions; both outputs are shipped in `data/`. `scale/build_jobs.py` retrieves under every condition and writes one prompt per distinct context with a `mapping.json`; `build_jobs.sbatch`, `build_extra_jobs.sbatch` (closed book, gold context) and `build_chunk_jobs.sbatch` are the paper's runs, whose mappings and retrieval statistics are in `results/jobs*/`. `scale/run_readers.py` answers the prompts with vLLM (`run_readers.sbatch` on the cluster, `run_readers_hf.py` as a fallback); every response of the paper's runs is in `results/reader_outputs.tar.gz`. `analysis/downstream_analysis.py` scores them against the float condition (paired difference, McNemar, TOST) and `downstream_tables.py` prints the tables.

**Parameters and timings.** `analysis/glwe_params.sage` runs the lattice estimator for each bit-width (about twenty minutes; `--cached` reuses `results/glwe_params.json`). The timings come from the `paper_bench` harness of the [vpir](https://anonymous.4open.science/status/vpir-pdr) crate, built with one of the features `d10`, `d11` and `d12` (the three parameter sets) and driven by its `scripts/bench.sbatch` and `scripts/bench_r2_chunks.sbatch`; each run appends one JSON line per shape. `results/vpir/` holds the files behind Table 4 and `analysis/cost_table.py` turns them into its rows.

## Data

SciFact, NFCorpus and Natural Questions are the BEIR distributions, downloaded on demand. `data/nq_meta/` holds the NQ-open development answers and the BEIR-NQ test queries and labels. `data/bioasq/` derives from BioASQ-QA, distributed by bioasq.org under its own terms. Not included: the embedding caches (re-encoded by the sweeps; about 5.5 GB per encoder for NQ), the prompt texts (regenerated by `build_jobs.py`), the raw BioASQ file, and API access for the hosted readers of `results/legacy_maxabs/`.
